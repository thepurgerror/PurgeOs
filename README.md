## Overview

**PurgeOS** is a custom-built web experience created for **ThePurgError**, a Minecraft gaming channel focused on PvP, Bedwars, Bedfight, and Minecraft 1.8.9 gameplay.

Inspired by terminal interfaces and system dashboards, PurgeOS presents creator information, video discovery, channel statistics, subscriber milestones, and community links through a distinctive gaming-oriented design.

Rather than functioning as a conventional creator landing page, the project brings these elements together in a dedicated interface designed around the channel's identity.

The website is publicly accessible and deployed on Netlify.

When working with API integrations:

- Keep private credentials and service-account files out of public repositories.
- Apply appropriate API-key restrictions and usage quotas.
- Remember that keys embedded in client-side JavaScript can be extracted by website visitors.
- Document any required configuration without publishing secret values.
- Handle unavailable API responses gracefully.

## Design Philosophy

PurgeOS is built around the idea that a creator website can be more than a collection of links.

Its terminal-inspired identity gives the project a cohesive visual direction, while the dashboard structure organises channel information and discovery features into a single experience.

The design combines:

- **Identity** — a recognisable gaming-oriented interface.
- **Clarity** — organised sections for content and channel information.
- **Functionality** — interactive features beyond static presentation.
- **Consistency** — a unified visual language throughout the website.

## Project Goals

- Establish a distinctive online identity for ThePurgError.
