# ⚔️ PurgeOS

### ThePurge_Error — Gaming, stats, and community in one place.

**PurgeOS is a custom terminal-inspired website built for ThePurge_Error, showcasing Minecraft PvP content, YouTube channel analytics, subscriber milestones, and community links through a distinctive gaming interface.**

🌐 **Live Website:** https://thepurgerror.netlify.app/  
▶️ **YouTube Channel:** https://www.youtube.com/@ThePurge_Error

---

## 🖥️ Overview

PurgeOS is the dedicated web experience for ThePurge_Error, a Minecraft gaming channel focused on Minecraft 1.8.9 PvP, Bedwars, and Bedfight.

Built around a terminal-inspired visual identity, the website transforms a conventional creator page into a custom gaming dashboard. It brings channel information, video discovery, subscriber milestones, analytics, and community access together in one place.

The project combines a distinctive interface with practical functionality, creating a central destination for viewers to explore the channel and follow its progress.

The website is publicly accessible and deployed on Netlify.
